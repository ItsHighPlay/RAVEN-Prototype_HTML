Discord Interactions Webhook Specification

⚡ Ponto de Extremidade de Interações (Interactions Endpoint)

Como o Discord trata Interações (Documentação Oficial)

De acordo com docs.discord.com/developers/topics (seção Interactions — Receiving and Responding), um aplicativo Discord pode receber interações de duas maneiras mutuamente exclusivas:

  1. Via Gateway WebSocket (Modo Padrão Atual da AquaBella): O servidor Ubuntu mantém conexão persistente com o Gateway do Discord. Para usar este modo, deixe o campo "URL do ponto de extremidade de interações" EM BRANCO no Discord Developer Portal.
  2. Via HTTP Webhook (`POST /api/discord/interactions`): Exige um servidor HTTPS dinâmico que valide os cabeçalhos criptográficos X-Signature-Ed25519 e X-Signature-Timestamp usando a PUBLIC_KEY da aplicação e responda {"type": 1} ao teste de PING. Sites estáticos (como GitHub Pages) retornam HTTP 405 para requisições POST e não devem ser colados nesse campo.

Rota Pronta no bella-server

O bella-server já implementa nativamente a rota POST /api/discord/interactions com verificação criptográfica Ed25519 (`PyNaCl`) caso deseje expor futuramente via Cloudflare Tunnel ou proxy HTTPS reverso.
